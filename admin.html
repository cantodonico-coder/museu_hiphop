Como criar o token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access → Only select repositories → museu_hiphop.
  3. Permissions → Contents → Read and write.
  4. Gere, copie e cole aqui.
O PIN aparece enquanto você cria, para conferir. Anote.
O token fica guardado criptografado neste aparelho, protegido pelo PIN.
